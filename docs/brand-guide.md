# InspiShelf 品牌与表达规范

这份文档帮助项目维护者、介绍者和媒体准确地展示 InspiShelf，不涉及软件内部标识的批量重命名。

## 品牌身份

**名称**：InspiShelf  
**中文识别**：InspiShelf · 灵感采集  
**类别描述**：Windows + Chrome 本地素材采集工具 / Local-first reference and media collector  
**品牌主句**：**把网页参考，存进自己的文件夹。**  
**英文主句**：**From scattered saves to a folder you actually own.**

### 一句话解释

> InspiShelf 帮助创作者将有权保存的网页图片、图文笔记和视频参考整理到本机素材库，支持部分网站的批量采集和视频抽帧。

不要把名称解释成平台官方工具、云端素材网站、通用爬虫框架或一键采集所有网站的工具。

### 它与普通收藏夹的区别

收藏夹主要保存**入口与链接**；InspiShelf 在受支持的内容页面中帮助用户保存**实际文件**，并按内容类型、来源平台和作品建立本地目录。不能因此保证任何第三方网页的完整可用性或永久可访问性。

## 品牌声音

- **清楚**：先说用户能得到什么，再解释实现机制。
- **克制**：不写“全网神器”“轻松搬空”“无损破解”“永久有效”“官方认证”。
- **面向创作者**：适合设计师、插画师、视频剪辑和内容研究；不过度限定只服务某一职业。
- **尊重内容权利**：可以说“收集参考”“本地整理”，不能把别人的内容描述成“拿来就能商用”。
- **不假装成熟**：当前需要 Windows 安装 + Chrome 手动加载扩展，没有商店版、一键自动升级或手机端。

## 视觉方向（供后续设计使用，并非已有视觉资产）

适合一个简洁的“资料卡片 / 文件夹 / 分层收纳”符号，传达收集、归档和视觉创作。建议采用清晰、低噪点、偏编辑设计的视觉语言：屏幕截图强调“网页 → 本地目录 → 可重新查找”，用真实界面操作建立可信度。

避免仿制 Pinterest、小红书、Instagram、Chrome 等平台的官方图标、配色组合或页面视觉作为品牌主体；演示素材优先使用自有作品或明确允许用于演示的内容。不要使用第三方平台 Logo 拼贴制造“官方合作”的印象。

## 名称与兼容性

截至已发布的 v0.5.13，安装包、Windows 快捷方式、托盘、Chrome 扩展显示的仍是「灵感采集 / Inspiration Collector」。**InspiShelf 目前是对外文档展示名**，还不是已经发布的新二进制品牌版本。更换程序内名称需独立构建、升级测试和发布。

名称完成过初步公开搜索，但**未完成商标、域名或软件商店的系统性权利检索**；本文件不主张名称具有可注册性或排他性。
