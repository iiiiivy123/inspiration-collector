InspiShelf · 灵感采集 — 开始使用

1. 启动后台
打开桌面或开始菜单的“灵感采集”。没有主窗口是正常的：图标在 Windows 右下角托盘，可能藏在 ∧ 里。

2. 首次加载 Chrome 扩展（只做一次）
右键托盘图标 → 复制扩展文件夹地址。
Chrome 地址栏打开 chrome://extensions，打开“开发者模式”，点击“加载未打包的扩展程序”。
弹出的文件夹窗口里按 Ctrl+L、Ctrl+V、回车，再点“选择文件夹”。选择 extension 文件夹本身。
看到“灵感采集”卡片且开关开启，加载就完成了。点击 Chrome 右上角拼图 → 图钉，将它固定。

3. 选择素材库
点击 Chrome 工具栏的灵感采集图标，在设置页选一个长期保存素材的文件夹。
更改素材库只影响以后的任务，不会搬走旧文件。“仅本次另存”只改变这一次。

4. 保存内容
打开你有权保存的作品网页，刷新一次，点击工具栏灵感采集 → 选择图片、图文、纯文字或视频 → 开始采集。
纯文字只保存 .md，评论可选；视频和批量模式取决于当前平台。
完成后点“打开文件夹”；也可以到设置里的采集记录打开实际保存位置。

5. 更新与退出
从 0.5.13 或更早版本升级：先在托盘右键“退出灵感采集”，再安装新版；不用卸载。
支持安全退出的新版本：安装器会请求空闲后台退出；正在采集时先等待完成或停止，再重试。
安装后去 chrome://extensions 为灵感采集点重新加载，并刷新作品网页。
关闭 Chrome 或本说明不会退出后台。结束使用时可从托盘菜单退出。

无法连接后台？先从开始菜单启动“灵感采集”，确认托盘图标，再重新打开扩展。

免安装 ZIP：解压完整文件夹后运行 InspirationCollector.exe，再加载旁边的 extension 文件夹。
配置和历史仍保存在 %LOCALAPPDATA%\InspirationCollector；这不是零痕迹绿色版。
不要与安装版同时运行。不要删掉或移动已加载的 extension 文件夹。
