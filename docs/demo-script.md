# InspiShelf｜30–45 秒真实演示脚本

目标：不用长篇解释，让第一次看到项目的人理解**它是什么、为什么有用、怎么用**。这是拍摄方案，不是已有视频或 GIF。

## 推荐视频：从网页到本地素材库

| 时间 | 画面 | 屏幕字 / 旁白 |
| --- | --- | --- |
| 0–5 秒 | 快速出现几个浏览器收藏夹 / 标签页，再切到空的本地文件夹 | 「收藏了很多参考，真正要用时还得重新找？」 |
| 5–11 秒 | 选一个**使用自己作品或已获授权示例**的页面，打开 Chrome 工具栏中的采集扩展 | 「在适配网页里，选择要保存的内容。」 |
| 11–18 秒 | 选择「图片」或「图文笔记」，展示本次保存目录并开始 | 「图片、图文 Markdown，按需要留存。」 |
| 18–25 秒 | 切到 Windows 文件资源管理器：对应的图片与 Markdown 文件真实落盘 | 「文件保存在自己的本地素材库。」 |
| 25–34 秒 | 选择一段**自有或许可演示的视频**，展示视频抽帧，再看到输出图片 | 「支持的视频，还可以提取参考画面。」 |
| 34–41 秒 | 展示采集记录 / 打开保存文件夹 | 「下次需要参考，不必重新翻收藏夹。」 |
| 41–45 秒 | 纯文字尾屏：InspiShelf + 项目网址 + Windows/Chrome | 「InspiShelf · 灵感采集。GitHub 可下载。」 |

字幕不要声称所有平台和所有媒体模式都支持。若某项功能在当前版本/场景不能稳定复现，应删除该镜头，不用合成一个虚假的成功流程。

## 8–10 秒 GIF（适合 GitHub README）

一条最有价值的真实工作流：  
**作品页打开扩展 → 点击保存 → Windows 文件夹出现结果文件**。

建议不做 10 秒内塞进六个平台的拼贴展示，而是用单一可信案例。GIF/视频里遮住个人本机路径、账号信息和任何访问令牌。

## 宣传封面文字

**主标题**：把网页参考，存进自己的文件夹。  
**副标题**：InspiShelf · Windows + Chrome 本地素材采集工具  
**功能字**：图片 / Markdown / 部分批量 / 视频抽帧

避免「全网无损」「破解下载」「所有平台一键批量」等承诺。

## 版权最小风险演示方案

- 优先使用自己创作的插画、笔记和视频作为网页及文件示例；必要时在自己的测试账号中发布再录屏。
- 也可使用明确允许重新分发及宣传演示的素材，记录许可与作者署名要求。
- 演示可展示适量平台交互，但不要把平台 Logo 直接当作本产品 Logo，不要制作误导性的官方合作视觉。
- 遮住账户名、评论者头像、私密消息、Cookie、授权令牌与可能含个人信息的路径。
- 不录制绕过访问限制、获取付费内容或批量搬运他人作品的流程。

## 后续添加到 README 的方式

确认录屏画面、许可、隐私和功能真实性后，将优化过的视频或 GIF 放到仓库允许公开的文档素材目录，再在 README 首屏添加一个真实预览链接。**不要先在 README 加不存在的图片地址**。
