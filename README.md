# InspiShelf · 灵感采集

**将允许保存的网页素材，整理进自己的本地资料库。**  
面向设计师、插画师、内容创作者与研究人员的 Windows + Chrome 工具：按需保存图片、图文笔记（Markdown）、纯文字或视频，并可在受支持的场景中批量收集、从视频提取参考画面。

## 它能做什么？

- **图片与视觉参考**：保存受支持作品页中的图片到自己指定的本地目录。
- **图文与 Markdown**：保存正文、来源信息以及按需选择的已加载评论、图片与本地 OCR 文字。
- **纯文字笔记**：仅保存 `.md`，不额外下载图片或视频。
- **视频与抽帧**：在支持的页面保存可用的视频文件，或保存视频后从中提取画面；也支持对已下载的本地视频抽帧。
- **部分平台的批量采集**：从受支持的作者页面或画板开始处理，并提供去重、记录、未完成任务继续或失败项重试等能力。
- **本地文件库**：按内容类型、平台和作品整理。可选择素材库位置，不要求用户配置 Python 或媒体依赖。

**适用设备**：Windows 10 / 11（64 位）和 Google Chrome。现在不是云同步服务、手机 App 或通用的“任意网站批量下载器”。

## 支持范围

| 网站 / 场景 | 当前支持与限制 |
| --- | --- |
| 小红书 | 受支持的单篇笔记图片、图文与视频相关模式；作者页面的部分批量能力 |
| X（原 Twitter） | 单帖；作者本人帖子列表的部分批量能力，不包含转帖 |
| Instagram | 帖子 / Reels 与作者帖子列表的部分采集能力 |
| Pinterest | 当前 Pin、具体画板；**不提供画板批量图文模式** |
| 花瓣 | 当前页面与部分批量图片采集 |
| B站（bilibili） | 视频稿件及 UP 主视频列表的相关模式，按文档所述条件保存或抽帧 |
| 其他普通网页 | 主要支持**当前页面图片**；不提供通用批量功能 |

网站结构、登录状态、权限、格式、内容是否已加载，都可能影响结果。**并不是每个平台都支持上表之外的所有功能**；以实际页面提供的选项为准。程序不提供绕过登录、付费、DRM 或访问控制的能力。

## 下载与开始使用

**[Windows 64 位安装包（Releases）](https://github.com/iiiiivy123/inspiration-collector/releases/latest)**

当前已发布版本：**v0.5.13**。安装文件名是 `InspirationCollector-0.5.13-Windows-x64-Setup.exe`；安装后界面仍显示「灵感采集」。

1. 从 Releases 的 **Assets** 下载 Windows 安装包；**不要**点击绿色 **Code** 按钮或下载 `Source code.zip`。
2. 安装并打开桌面的「灵感采集」。它会在 Windows 系统托盘运行，不会默认弹出主窗口。
3. 在 Chrome 地址栏打开 `chrome://extensions`，启用开发者模式，加载安装目录中的 `extension` 文件夹。可从托盘菜单复制该文件夹路径。
4. 固定扩展到 Chrome 工具栏；第一次使用选择素材库目录。
5. 打开目标作品页，点击扩展，根据当前页面可用功能选择并保存。

完整安装、更新、卸载及排错步骤请看 [使用教程](docs/usage.md)。

> 安装包当前尚未签名，Windows 可能提示“未知发布者”。请核实下载来源，不要为安装关闭系统安全防护。当前没有自动更新功能。

## 本地保存示例

```text
你选择的素材库/
├─ 图片/平台/作品/
├─ 图文/平台/作品/
├─ 视频/平台/作品/
└─ 批量/平台/作者或画板/
```

纯文字笔记通常归入图文或批量。更改默认素材库**不会自动移动旧文件**；如需找回旧采集内容，可在“采集记录”里打开原文件夹。

## 常见问题

**Q：有没有把 Pinterest 画板图片保存到电脑的工具？**  
A：InspiShelf 支持从具体画板开始采集可识别的 Pin；结果存储在本机。画板内容必须实际可访问，不能保证获取未加载或受限内容。

**Q：小红书图文能保存成 Markdown 吗？**  
A：在受支持的单篇笔记中，可以选择“图文笔记”或“纯文字 · Markdown”。评论仅包括页面已加载并能识别的部分。

**Q：视频能转成多张参考图吗？**  
A：可在适用场景中保存并抽帧，也可以使用本地视频抽帧；抽帧点数、间隔和画面相似度合并都有使用限制。

**Q：会把采集素材上传到项目服务器吗？**  
A：现有版本的保存服务运行在你自己的电脑上，文件写入所选本地目录。浏览器与后台仍会请求来源网站或其媒体 CDN；请查看 [隐私说明](docs/rights-and-privacy.md)。

**Q：公开能看到的图片是不是都可以下载并商用？**  
A：**不是。** 公开可见不等于已获得复制、再发布或商业使用的许可。仅在你拥有相应权利、获得许可或适用法律明确允许的范围内使用。详见 [版权与使用边界](docs/rights-and-privacy.md)。
