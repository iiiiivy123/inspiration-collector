# 灵感采集

把网页中的图片、图文、纯文字和视频保存到自己的电脑，支持部分平台的批量采集与视频抽帧。

## 下载

### [下载 Windows 安装包（64 位）](https://github.com/iiiiivy123/inspiration-collector/releases/download/v0.5.13/InspirationCollector-0.5.13-Windows-x64-Setup.exe)

适用于 **Windows 10 / 11 + Chrome**。已内置 Python 和媒体组件，无需配置环境。

下载的文件名是 `InspirationCollector-0.5.13-Windows-x64-Setup.exe`，双击安装即可。**不要点绿色 Code 按钮，也不要下载 Source code.zip，那些是给开发者看的源码。**

[版本与更新说明](https://github.com/iiiiivy123/inspiration-collector/releases/latest) · [完整使用教程](docs/usage.md)

> 安装包暂未签名，Windows 可能提示未知发布者。请确认来源，不要关闭安全防护。

## 安装后怎么用

1. 启动桌面的「灵感采集」，它在右下角系统托盘运行，不弹主窗口。
2. 按 [加载扩展步骤](docs/usage.md#2-首次把扩展添加到-chrome)，在 Chrome 选择安装目录中的 `extension` 文件夹。
3. 看到「灵感采集」卡片并已开启，就可以关闭扩展管理页。从 Chrome 拼图菜单将它固定到工具栏。
4. 打开作品网页，点击工具栏里的灵感采集，选择保存位置和内容，开始采集。

首次加载只需做一次。以后使用先启动桌面程序，再从 Chrome 工具栏打开扩展。右键托盘可打开使用说明或退出后台。

## 支持的内容

| 模式 | 用途 |
| --- | --- |
| 图片 | 保存当前作品图片 |
| 图文笔记 | Markdown 正文，可附图片、已加载评论和本地 OCR |
| 纯文字 | 只保存 Markdown，评论可选，不下载图片视频 |
| 视频 | 保存视频，或保存并抽帧 |
| 批量 | 作者或画板；批量视频跳过图片帖，按视频数量计算 |

适配小红书、X、Instagram、Pinterest、花瓣及 B站，具体模式以页面可选项为准。其他网页主要支持当前页图片；不提供通用批量。

B站使用可用的兼容音视频源本地合并，不绕过付费或访问限制；过滤网页广告卡片不等于剪掉视频内广告。网页改版、登录状态和格式可能影响结果。

## 文件保存在哪里

第一次在扩展设置里选择「素材库位置」，之后按以下层级保存：

```text
你选择的素材库/
├─ 图片/平台/作品/
├─ 图文/平台/作品/
├─ 视频/平台/作品/
└─ 批量/平台/作者或画板/
```

纯文字归入图文或批量。弹窗「选择…」只改变本次位置，不改变长期素材库。更改素材库不会搬迁旧文件；找旧作品请在采集记录里点「打开文件夹」。
